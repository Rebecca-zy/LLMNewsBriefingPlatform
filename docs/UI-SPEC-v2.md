# AI热点推送系统 - UI设计说明（V3）

## 1. 设计定位
1. 对客详情页，不做后台管理台风格。
2. 浅色科技风：蓝系主色、低噪声背景、高可读内容卡片。
3. 重点强调“趋势摘要 + 热点条目 + 日期切换”。

## 2. 页面结构（当前实现）
1. 顶栏：品牌文案 + 自动更新状态。
2. 头部卡：日期标题、元信息胶囊、趋势摘要、操作按钮。
3. 内容卡：热点条目区（左）+ 日期胶囊（右上）。
4. 条目卡：标题、应用领域标签、简介、影响解读、原文链接。

## 3. 样式原则
1. 边框弱化，优先用留白与层次分组。
2. 字号分级明确：
- H1: 30-46
- H2: 26-36
- 条目标题: 24-32
- 正文: 16-20
- 辅助文案: 13-15
3. 色彩克制：主蓝 + 辅助浅蓝，不使用高饱和多色混搭。

## 4. 响应式规则
1. Desktop（>1024）：完整布局与按钮同排。
2. Tablet（768-1024）：收紧留白与字号。
3. Mobile（<768）：
- 顶栏纵向排布
- 按钮与日期胶囊换行
- 超窄屏（<480）按钮全宽

## 5. 关键交互
1. 日期胶囊点击切换简报。
2. 更新简报触发生成流程。
3. 企业微信推送基于当前选中简报执行。
4. 分享按钮复制当前页面 URL。

## 6. 不展示内容（对客约束）
1. 抓取成功率、内部错误率、调度耗时等运维指标。
2. 内部调试字段或原始评分字段。
